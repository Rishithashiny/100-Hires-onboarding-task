### Issues Encountered and Resolutions
#### Issue 1: Understanding GitHub Terminology
Challenge:
Initially, I was unfamiliar with concepts such as GitHub repositories, commits, pushes, and version control.
Resolution:
Researched and learned the purpose of GitHub, repositories, and Git workflows before proceeding with the setup process.
Outcome:
Developed a foundational understanding of GitHub and repository management.
#### Issue 2: Confusion Between Git, GitHub, and GitHub Desktop
Challenge:
At the beginning, it was unclear how Git, GitHub, and GitHub Desktop were related.
Resolution:
Learned the distinction:
* Git = version control system
* GitHub = online repository hosting platform
* GitHub Desktop = desktop application for managing repositories
Outcome:
Successfully understood the workflow between local files and GitHub repositories.
#### Issue 3: Opening the Repository in Cursor
Challenge:
While attempting to clone and open the repository, there was confusion regarding how Cursor should connect to GitHub.
Resolution:
Used GitHub Desktop to access the repository locally and then opened the repository folder directly within Cursor.
Outcome:
Successfully accessed and edited the repository in Cursor.
#### Issue 4: Understanding the Purpose of README.md
Challenge:
Initially unfamiliar with why README.md files are commonly used in GitHub repositories.
Resolution:
Learned that README.md serves as the primary project documentation and is automatically displayed on the repository homepage.
Outcome:
Successfully documented the project using Markdown.
